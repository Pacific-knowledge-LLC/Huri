# Documentation Huri

Ce site Docusaurus rassemble la documentation fonctionnelle, technique et
opérationnelle de Huri. Le contenu publié se trouve dans `docs/`.

## Développement local

```bash
npm install
npm run start
```

## Vérification

```bash
npm run typecheck
npm run build
```

Le build statique est généré dans `build/`. Le dépôt principal ne déploie pas
automatiquement ce site documentaire.
